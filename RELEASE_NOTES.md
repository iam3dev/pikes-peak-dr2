## Pikes Peak for DiRT Rally 2.0 — Early Preview

Unofficial port replacing the supported Spain route. Includes fixes for disappearing trees, pre-start cameras and the vehicle setup scene.

### Install
Extract the entire ZIP, close the game and run **PikesPeakSetup.exe**. Select the installed game folder and a separate backup folder, then **Check compatibility → Install mod**. Python is not required. Keep the backup folder for **Restore backup**.

### Installer
English GUI, DPI-aware text, verified backup status, automatic compatibility checks and compact backups of the changed tree-settings blocks. A fresh install saves about 2.35 GB of backups and stages up to 6.24 GB of temporary data; space is checked per drive.

### Tested
User-confirmed installation, gameplay and restoration on the primary PC. Automated full-size archive round trip, backup validation and injected-failure rollback tests passed.

### Known issues
Terrain near 11 km and distant tree pop-in remain. Full-route, other weather/event modes, online behaviour, second-PC compatibility and controlled performance testing are pending. This is a route replacement, not an added menu location.
