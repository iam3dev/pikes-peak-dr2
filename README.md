# Pikes Peak for DiRT Rally 2.0

**Unofficial Community Port · Early Preview v0.6.0**

*A classic climb. A new home.*

Experience the iconic Pikes Peak stage from DiRT Rally in DiRT Rally 2.0 — from forest-lined roads to exposed mountain slopes and sweeping views.

**This mod replaces the supported Spain route. It does not add a separate location to the menu.**

## Download and install

**[Download the Windows installer](https://github.com/iam3dev/pikes-peak-dr2/releases/tag/v0.6.0)**

1. Download the ZIP, extract all files and run **PikesPeakSetup.exe**.
2. Close DiRT Rally 2.0.
3. **Game folder:** select the installed game folder containing `dirtrally2.exe`.
4. **Backup folder:** choose where to save your original files. Keep this folder for restoration.
5. Click **Check compatibility**, then **Install mod**.

Start with a dry daytime event on the replaced Spain route. The installer checks compatibility and available disk space before making changes.

## Restore Spain

Close the game, select the same game and backup folders, then click **Restore backup**. This returns the game files to their state before installation. The button is available only when a suitable backup is found.

## Known issues

- Terrain and landscape shading around **11 km** need improvement.
- Distant trees can visibly pop into view.
- Full-route testing is still in progress.
- Other weather conditions, event modes, online play and performance across different PCs have not been fully tested.
- Mods changing the same map or tree settings may conflict.

[Report an issue](https://github.com/iam3dev/pikes-peak-dr2/issues) with your event/weather settings, distance along the route, and a screenshot or short video. For installation problems, include the activity log.
